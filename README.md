# TOP100 · Админ-панель контент-плана — прототип

Кликабельный прототип системной версии контент-плана Продюсерского центра для разработчика.
Один файл `index.html`, без сборки и зависимостей. Данные слотов — план W37 эксперта Кати,
статусы и имена команды демонстрационные (демо-дата вс 06.09.2026).

Что смотреть: карточка эксперта → воронка недели → таблица плана (клик по строке открывает
карточку слота) → вкладки «Календарь эксперта», «Уведомления», «Задачи (не MVP)»,
«Поля и правила» (маппинг колонок на plan.yaml и правила флоу).
